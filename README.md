# Hypertension Risk Prediction Among Bangladeshi People

## Overview

This project applies machine learning techniques to predict hypertension risk among Bangladeshi individuals using demographic, lifestyle, and clinical factors.

## Dataset

The dataset contains information on:

- Age
- Gender
- Height
- Weight
- BMI
- Systolic Blood Pressure
- Diastolic Blood Pressure
- Smoking Status
- Salt Intake
- Sleep Duration
- Stress Level
- Family History of Hypertension

## Models Used

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)
6. Gradient Boosting
7. XGBoost

## Evaluation Metrics

- Accuracy
- ROC-AUC
- Cross Validation Accuracy

## Results

| Model | ROC-AUC |
|---------|---------|
| XGBoost | 96.20% |
| Gradient Boosting | 96.14% |
| Random Forest | 96.01% |
| SVM | 95.59% |
| Logistic Regression | 94.65% |
| KNN | 91.41% |
| Decision Tree | 91.08% |
