# Hypertension Risk Factor Analysis in Bangladesh

This project focuses on analyzing and predicting hypertension risk factors in Bangladesh using Machine Learning techniques.

The project includes data analysis, dataset description, preprocessing, multiple Machine Learning models, model comparison, and evaluation to identify important factors associated with hypertension.

## Project Objectives

- Analyze hypertension-related risk factors in Bangladesh
- Explore and understand the dataset
- Perform data preprocessing and preparation
- Train multiple Machine Learning models
- Compare model performance
- Evaluate prediction results
- Identify important factors related to hypertension risk

## Dataset

The dataset contains information related to hypertension and its potential risk factors in Bangladesh.

The project includes separate datasets for:

- Hypertension cases
- Non-hypertension / hypertension risk factor data

## Machine Learning

Several Machine Learning models are implemented and compared to evaluate their performance for hypertension prediction.

The project includes:

- Data preprocessing
- Model training
- Cross-validation
- Performance comparison
- Evaluation of prediction results
